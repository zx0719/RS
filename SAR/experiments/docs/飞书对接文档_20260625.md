## 一、当前进展汇报

### 1.1 项目背景

基于SAR卫星图像实现军事目标自动检测，目标是支持**飞机（>20m）、轮船（>80m）、机场、港口**四类目标的实时/延时检测。

### 1.2 已完成的模型训练

目前基于 YOLOv8m-OBB 训练了两版核心检测模型：

| 版本 | 目标类别 | 类别数 | 精确率(P) | 召回率(R) | mAP@50 | 状态 |
|------|----------|--------|-----------|-----------|--------|------|
| v4-multiclass | 船舶 + 飞机 + 坦克 + 桥梁 + 港口 | 5 | 84.9% | 82.9% | 87.54% | ⚠️ 召回率不足 |
| **v5-2class** | 船舶 + 飞机 | 2 | **93.4%** | **93.3%** | **95.98%** | ✅ **推荐模型** |

> v4 → v5 的迭代思路：5 类混合训练时类间干扰导致 recall 上不去（82.9%），
> 因此 v5 **聚焦船舶+飞机两类核心目标**，精度和召回率均超越公司要求。

### 1.5 技术路线

```
SAR图像输入 (GeoTIFF/JPEG, 8bit, P谱段)
  │
  ├─ [M1] 元数据解析 (GDAL)
  │    └─ 提取GSD、地理参考、成像参数
  │
  ├─ [M2] YOLOv8m-OBB 目标检测
  │    └─ 船舶 + 飞机 旋转框检测
  │    └─ 推扫成像切片检测
  │
  ├─ [M3] 坐标地理化
  │    └─ 像素坐标 → WGS84经纬度 (GDAL变换)
  │
  ├─ [M4] 证据融合 (Evidence JSON)
  │    └─ 检测结果 + 坐标 + 元数据 → 结构化证据
  │
  ├─ [M5] LLM通报生成 + Word文档组装
  │    └─ 纯文本LLM读取证据JSON → 情报通报正文
  │    └─ python-docx生成.docx
  │
  └─ 输出：标准通报.docx + 证据JSON + 检测标注图
```

> **设计原则**：事实由检测工具给出，文字由LLM组织——数量/类别/坐标等关键信息来自工具输出，LLM仅负责语言生成，杜绝幻觉。

### 1.6 🔴 SAR域专项说明

#### 我们目前只做SAR

我方所有模型训练、验证、测试**100%基于SAR图像数据**：

| 维度 | 说明 |
|------|------|
| 数据域 | **仅SAR** (合成孔径雷达)，P谱段8bit推扫切片 |
| 未涉及 | 光学遥感 (可见光/红外/多光谱) |
| 模型适配 | YOLOv8m-OBB 在SAR域上fine-tune，未在其他域验证 |
| 域迁移局限 | SAR特有的相干斑噪声、几何畸变、方位模糊等问题，模型已针对性训练 |

**SAR vs 光学关键差异**：
- SAR图像无色彩信息（灰度），目标形态因方位角变化大
- 相干斑噪声 (speckle noise) 是SAR特有，光学图像无此问题
- 目标边缘可能模糊（多普勒效应），需要旋转框适配
- 机场跑道在SAR中呈暗色调（光滑表面镜面反射），港口水域呈暗色调

#### 需要确认的测试域

| 问题 | 建议确认 |
|------|----------|
| **公司是否已知我方仅做SAR？** | 如果公司期望同时覆盖光学遥感，需要额外标注和训练 |
| **公司的测试数据是什么谱段？** | 是否是P谱段SAR？是否有光学数据混入？ |
| **不同场景下的域差异** | 近岸 vs 远海、平地 vs 山地、不同海况 — 是否都需要测试？ |
| **是否能提供实际业务数据样本做域适应？** | 如有少量P谱段真实切片样本，可做域适应微调提升泛化能力 |
