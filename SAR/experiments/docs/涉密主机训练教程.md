## 模型 1：Gate 场景分类器（3 类）

### 作用

判断 SAR 图像属于哪种场景，决定是否触发 FastSAM 分割。

```
输入: SAR 图像瓦片 (512×512)
输出: harbor / airport / none
```

### 训练命令

```bash
cd offline_training_pack

python code/modules/classifier/train_gate.py \
    --data-root /path/to/data_script_run \
    --output weights/gate_resnet18.pt \
    --epochs 50 \
    --batch-size 32 \
    --device cuda:0
```

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--data-root` | **必填** | data_script_run 目录路径 |
| `--output` | `gate_resnet18.pt` | 输出权重路径 |
| `--epochs` | 50 | 训练轮数 |
| `--batch-size` | 32 | 批次大小 |
| `--lr` | 1e-4 | 学习率 |
| `--device` | `cuda:0` | GPU 设备 |
| `--patience` | 10 | 早停轮数 |

### 预期输出

```
[Gate] Device: cuda:0
[Gate] Classes: ['harbor', 'airport', 'none']
[Gate] Data root: /path/to/data_script_run
[Gate] Found 1200 detection images
[Gate] Label distribution: harbor=100, airport=700, none=400
[Gate] Train: 1020, Val: 180
[Gate] Class weights: [2.5, 0.8, 1.2]
Epoch   1/50 | loss=0.8523 | acc=0.7200 | F1=0.6800
Epoch   2/50 | loss=0.6234 | acc=0.8100 | F1=0.7900
...
[Gate] Early stopping at epoch 28
[Gate] Saved to weights/gate_resnet18.pt (F1=0.9200)
```

### 预期时间

~1 小时（ResNet-18，千张图，50 epoch）

### 常见问题

| 问题 | 解决 |
|------|------|
| `Label distribution: harbor=0, airport=0, none=all` | 检查 `segmentation/train/polygons/` 是否为空 |
| `Found 0 detection images` | 检查 `detection/train/images/` 路径 |
| 所有图都被判为 none | polygons 目录缺失或 coarse_class 不匹配 |

## 模型 2：舰船细分类器（16 类）

### 作用

从 YOLO 粗检测的 ship 框中裁剪 ROI，细分为 16 类舰船。

```
输入: 舰船 ROI 切片 (128×128)
输出: 16 类舰船 subtype
```

### 训练命令

```bash
cd offline_training_pack

python code/modules/classifier/train_ship_cls.py \
    --data-root /path/to/data_script_run \
    --output weights/ship_cls_resnet18.pt \
    --epochs 100 \
    --batch-size 32 \
    --device cuda:0
```

### 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--data-root` | **必填** | data_script_run 目录路径 |
| `--output` | `ship_cls_resnet18.pt` | 输出权重路径 |
| `--epochs` | 100 | 训练轮数 |
| `--batch-size` | 32 | 批次大小 |
| `--lr` | 1e-4 | 学习率 |
| `--device` | `cuda:0` | GPU 设备 |
| `--patience` | 20 | 早停轮数 |

### 数据提取逻辑

脚本自动从 `detection/` 中：
1. 遍历所有 `labels/*.txt`（YOLO HBB 格式）
2. 读取 `metadata/samples.jsonl` 获取 `coarse_class`
3. 筛选 coarse_class 属于舰船类别的实例
4. 从原图中裁剪 bbox 区域 → 保存为临时 chip
5. 按 fine_class 分配到 16 个类别

### 预期输出

```
[ShipCls] Device: cuda:0
[ShipCls] Target classes (16): ['military_auxiliary', 'combat_ship', ...]
[ShipCls] Scanning 1200 images for ship instances...
[ShipCls] Extracted 2100 ship chips
  military_auxiliary: 130
  combat_ship: 140
  liquid_cargo: 125
  ...
[ShipCls] Train: 1785, Val: 315
Epoch   1/100 | loss=2.4521 | val_acc=0.3200
Epoch   2/100 | loss=1.8934 | val_acc=0.4500
...
Epoch  45/100 | loss=0.4234 | val_acc=0.8700
[ShipCls] Early stopping at epoch 45
[ShipCls] Saved to weights/ship_cls_resnet18.pt (acc=0.8700)
```

### 预期时间

~1 小时（2100 个 chip，100 epoch）

### 常见问题

| 问题 | 解决 |
|------|------|
| `Extracted 0 ship chips` | 检查 coarse_class 值是否在 `_SHIP_COARSE` 关键词集合中 |
| 某类样本数为 0 | 正常——该类在数据中无标注；分类器仍可输出但无训练信号 |
| `temp_ship_chips` 占用空间 | 可手动删除，每次训练会覆盖 |
| 所有 chip 标记为 other_vessel | fine_class 字段为 null → 正常回退行为 |

## 模型 3：飞机细分类器（5 类）

### 作用

从 YOLO 粗检测的 aircraft 框中裁剪 ROI，细分为 5 类飞机。

```
输入: 飞机 ROI 切片 (128×128)
输出: 5 类飞机 subtype
```

### 训练命令

```bash
cd offline_training_pack

python code/modules/classifier/train_aircraft_cls.py \
    --data-root /path/to/data_script_run \
    --output weights/aircraft_cls_resnet18.pt \
    --epochs 100 \
    --batch-size 32 \
    --device cuda:0
```

### 参数说明

同舰船分类器。

### 预期输出

```
[AircraftCls] Device: cuda:0
[AircraftCls] Target classes (5): ['combat_aircraft', 'transport_aircraft', ...]
[AircraftCls] Scanning 1200 images for aircraft instances...
[AircraftCls] Extracted 2100 aircraft chips
  combat_aircraft: 420
  transport_aircraft: 400
  combat_support_aircraft: 380
  helicopter: 450
  other_aircraft: 450
[AircraftCls] Train: 1785, Val: 315
Epoch   1/100 | loss=1.8521 | val_acc=0.4500
...
[AircraftCls] Saved to weights/aircraft_cls_resnet18.pt (acc=0.9100)
```

### 预期时间

~30 分钟（2100 个 chip，100 epoch）

### 常见问题

| 问题 | 解决 |
|------|------|
| `Extracted 0 aircraft chips` | coarse_class 未匹配 `_AIRCRAFT_COARSE` |
| 运输机全部标记为 other_aircraft | 确认 class_labels.py 中 "运输机" → transport_aircraft 映射正常 |

## 三模型训练完成后的产出

```
weights/
  gate_resnet18.pt          # Gate 场景分类器 (~44MB)
  ship_cls_resnet18.pt      # 舰船细分类器 (~44MB)
  aircraft_cls_resnet18.pt  # 飞机细分类器 (~44MB)
```

三个 `.pt` 文件拷回联网机器，与 M1 YOLO 权重一起组成完整推理管线。

## 自动化脚本（可选）

```bash
#!/bin/bash
# train_all.sh — 一键训练三个模型
DATA_ROOT="/path/to/data_script_run"
OUTPUT_DIR="./weights"
DEVICE="cuda:0"

mkdir -p "$OUTPUT_DIR"

echo "=== 1/3: Gate 场景分类器 ==="
python code/modules/classifier/train_gate.py \
    --data-root "$DATA_ROOT" \
    --output "$OUTPUT_DIR/gate_resnet18.pt" \
    --epochs 50 --batch-size 32 --device "$DEVICE"

echo "=== 2/3: 舰船细分类器 ==="
python code/modules/classifier/train_ship_cls.py \
    --data-root "$DATA_ROOT" \
    --output "$OUTPUT_DIR/ship_cls_resnet18.pt" \
    --epochs 100 --batch-size 32 --device "$DEVICE"

echo "=== 3/3: 飞机细分类器 ==="
python code/modules/classifier/train_aircraft_cls.py \
    --data-root "$DATA_ROOT" \
    --output "$OUTPUT_DIR/aircraft_cls_resnet18.pt" \
    --epochs 100 --batch-size 32 --device "$DEVICE"

echo "=== 完成 ==="
ls -lh "$OUTPUT_DIR"/
```
