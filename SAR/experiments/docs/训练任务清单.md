## 当前机器 (联网)

### ☐ 任务 1: 准备 M1 YOLO 数据集 (ship/aircraft 2类)

**输入**：v4-multiclass 数据集（5类）→ 过滤为 2类

**操作**：
```bash
# 复制 v4-multiclass 转换脚本，修改：
#   - 去掉 tank(2), bridge(3), harbor(4) 的类别映射
#   - nc: 2, names: ['ship', 'aircraft']
#   - 输出目录: datasets/v5-2class/

cd /mnt/data/zhuxiang/SAR_experiments/datasets
cp -r v4-multiclass v5-2class
# 编辑 v5-2class/dataset.yaml → nc: 2, names: ['ship', 'aircraft']
# 编辑 v5-2class/convert_v5_2class.py → 过滤类别映射
python v5-2class/convert_v5_2class.py
```

**产出**：`datasets/v5-2class/dataset.yaml` + train/val 数据

---

### ☐ 任务 2: 训练 M1 YOLO (ship/aircraft 2类粗检测)

**输入**：`datasets/v5-2class/dataset.yaml`

**命令**：
```bash
cd /mnt/data/zhuxiang/SAR_experiments

torchrun --nproc_per_node=2 train_v5_2class.py
# 或手动:
python -c "
from ultralytics import YOLO
model = YOLO('yolov8m-obb.pt')
model.train(
    data='datasets/v5-2class/dataset.yaml',
    epochs=100, imgsz=640, batch=32, device='0,1',
    optimizer='AdamW', lr0=1e-3, cos_lr=True,
    patience=30, amp=True, workers=8,
    name='v5-2class'
)
"
```

**产出**：`runs/v5-2class/weights/best.pt` (~2天，建议后台跑)

**预计时间**：~1天（双A800）

---

### ☐ 任务 3: 准备离线训练包 → USB 拷入涉密主机

**打包内容**：
```bash
mkdir -p /home/zhuxiang/RS/SAR/experiments/offline_training_pack

# 代码
cp -r modules/classifier offline_training_pack/code/
cp -r modules/segmentation offline_training_pack/code/
cp modules/class_labels.py offline_training_pack/code/

# 训练脚本
cp modules/classifier/train_gate.py offline_training_pack/code/
cp modules/classifier/train_ship_cls.py offline_training_pack/code/
cp modules/classifier/train_aircraft_cls.py offline_training_pack/code/

# 公开辅助数据
mkdir -p offline_training_pack/data/airport_scenes
cp -r /mnt/data/mm_data/SAR/dection/星载SAR机场检测数据集\(SAR-Airport-1.0\)/Airport_Dataset_v0_images/* \
    offline_training_pack/data/airport_scenes/

# 负样本 (从公开数据随机抽 ~2000 张不含港口机场的图)
python scripts/sample_negative_scenes.py \
    --public-data /mnt/data/mm_data/SAR/SARDet_100K/data/Images/ \
    --output offline_training_pack/data/negative_samples/ \
    --count 2000

# 打包
tar -czf offline_training_pack.tar.gz offline_training_pack/
```

**产出**：`offline_training_pack.tar.gz` → USB 拷入涉密主机

### ☐ 任务 5: 训练 Gate 场景分类器 (3类: harbor/airport/none)

**前置**：私人 300 张数据已挂载，路径已知

**命令**：
```bash
python code/train_gate.py \
    --harbor-dir /data/private/harbor_scenes/ \
    --airport-dir data/airport_scenes/ \
    --negative-dir data/negative_samples/ \
    --output weights/gate_resnet18.pt \
    --epochs 50 --batch-size 32 --device cuda:0
```

**产出**：`weights/gate_resnet18.pt`
**预计时间**：~1小时
